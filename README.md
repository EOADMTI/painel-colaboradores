# Painel — Central de Colaboradores

Página estática com os totais da Central de Colaboradores (sem dados pessoais: nenhum nome, CPF ou endereço).

Publicada pelo GitHub Pages em https://eoadmti.github.io/painel-colaboradores/

Os números são atualizados sob pedido: as consultas são somente leitura na base e o resultado é gravado em `index.html`.
